## play-publisher info

Display the package name and type of the app

### Synopsis

Prints information about the provided app in the following form:

File name:        {file name}
Application type: {aab|apk}
Package name:     {package name}
Version name:     {version name}
Version code:     {version code}

```
play-publisher info <file> [flags]
```

### Options

```
  -h, --help   help for info
```
