## play-publisher upload

Upload an APK or AAB to the Play Store

### Synopsis

Upload an APK or AAB to the Play Store.

The service account, which has been linked to the Play Store, is needed.
The track is optional and defaults to "internal", if omitted

```
play-publisher upload <file> [flags]
```

### Options

```
  -h, --help                     help for upload
  -s, --service-account string   the service account (required)
  -t, --track string             the track (default "internal")
```
